Ohio State Football Analytics

An interactive Power BI dashboard analyzing Ohio State football performance across the 2015–2026 seasons. Using data from the CollegeFootballData API, this project brings together team, player, and historical statistics to explore performance trends and provide an interactive view of the program.

Tools & Technologies

Power BI, DAX, Power Query, CollegeFootballData API

Project Scope

2015–2026 seasons

Project Type

Data Analytics & Visualization

Key Features

  • Season overview and team performance analysis
  • Historical team statistics and trends
  • Player statistics and performance breakdowns
  • Next game preview
  • Interactive dashboard navigation and visualizations
